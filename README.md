# WhaleFlow Intelligence 🐋

An AI-powered crypto investment platform that tracks whale traders, validates market conditions, and forecasts performance through a sophisticated multi-agent system.

## 🚀 Features

### 1. Smart Whale Detection 🧠
- Identifies and analyzes top-performing whale traders
- Tracks portfolio sizes, win rates, and trading patterns
- Provides detailed whale trader profiles and success metrics

### 2. Real-Time Market Analysis 📊
- **Short-term Analysis:**
  - Live technical indicators
  - Market sentiment analysis
  - Real-time price movement validation
- **Long-term Analysis:**
  - Whale trading pattern recognition
  - Historical trend analysis
  - Risk assessment metrics

### 3. Performance Forecasting 📈
- AI-driven price prediction models
- Visual trend analysis through interactive charts
- Comprehensive investment recommendations

## 🛠️ Technology Stack

- **Frontend:** Streamlit
- **Backend:** Python
- **AI/ML:** OpenAI API
- **Data Sources:** 
  - MCP Jenius Server (Real-time market data)
  - Whale trading databases
  - Historical crypto price data

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/whaleflow-intelligence.git
cd whaleflow-intelligence
```

2. Create and activate a virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

4. Set up environment variables:
```bash
# Create .env file with the following:
OPENAI_API_KEY=your_openai_api_key
JENIUS_MCP_TOKEN=your_mcp_token
```

5. Run the application:
```bash
streamlit run main.py
```
